# Mi Cuentika

## Descripción del proyecto

Mi Cuentika es una aplicación orientada a facilitar
la administración y el control de pequeños negocios,
especialmente pulperías.

## Objetivo

Organizar las operaciones del negocio mediante
herramientas que permitan gestionar productos,
inventario, clientes, compras, ventas, fiados y abonos.

## Arquitectura

El proyecto utiliza una arquitectura de tres capas:

- Presentation: presentación e interacción con el usuario.
- Business: lógica y reglas del negocio.
- Data: acceso y comunicación con la base de datos.

## Tecnologías

- Python
- MySQL
- MySQL Workbench
- Visual Studio Code
